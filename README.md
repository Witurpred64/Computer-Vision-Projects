
# Computer Vision Projects

This repository contains a collection of advanced computer vision projects, demonstrating various techniques in object detection, image segmentation, and generative models. Each project is designed to be modular and easily extensible.

## Projects Included
- **Object Detection with YOLOv5:** Implementation and training of YOLOv5 for custom object detection tasks.
- **Semantic Segmentation with U-Net:** A U-Net based model for pixel-level image segmentation.
- **Generative Adversarial Networks (GANs):** Examples of GANs for image generation and style transfer.
- **Image Classification with ResNet:** Fine-tuning ResNet models for various image classification benchmarks.

## Technologies
- PyTorch
- OpenCV
- Albumentations
- scikit-learn

## Getting Started
Each project has its own directory with a dedicated `README.md` for setup and usage instructions.
